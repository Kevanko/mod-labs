# mod-labs

Modeling and operations research labs in Python, including CPM analysis, combinatorial sampling, and report generation.

## Overview

This repository collects laboratory assignments focused on graph-based modeling, critical path analysis, combinatorial tasks, and generated reports.

## Structure

- `lab-1` - introductory modeling tasks
- `lab-2` - critical path method and report generation
- `lab-3` - experimental modeling scenarios and visualizations
- `lab-4` - sampling with and without replacement

## Stack

Python, Makefile, Markdown, DOCX reports.

## Notes

The repository is organized as a set of independent academic labs.
